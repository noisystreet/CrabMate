## 总览

- **后端（`src/` + workspace crates）**：OpenAI 兼容 `chat/completions`、Agent 回合、HTTP/SSE、工具、工作区与会话。
- **官方 UI（Client 仓 [frontend](https://github.com/noisystreet/crabmate-client/tree/main/frontend)）**：Leptos + WASM（Trunk）；本仓 `serve` **默认纯 API**；同机托管 SPA 用 **`--with-web`** + **`CM_WEB_STATIC_DIR`**。本机开发默认同级 `../crabmate-client`（Playwright 转发可用 **`CRABMATE_CLIENT_DIR`**）。
- **CLI / TUI（`runtime/`）**：与 Web 共用 **`run_agent_turn`** 与工具执行面。
- **开发 / 打包容器（可选）**：根目录 **`Dockerfile`** 为 **Ubuntu 24.04** **工具链**镜像（Rust + `cargo-deb`；glibc **2.39** / deb **`libc6 (>= 2.39)`**；**非**生产运行镜像）。`docker build -t crabmate-dev .`（仅宿主机 DNS 异常时再加 `--network=host`），再 `docker run --rm -it -v "$PWD":/workspace -w /workspace crabmate-dev`；或 **`make package-docker`**。UI/Trunk 仍在 Client 仓。

## 架构设计

### 进程与分层

单体 **Tokio** 进程：Axum HTTP + `runtime` CLI；共享 `AgentConfig`、tools、`run_agent_turn`。

1. **接入**：`web/`、`serve` / `cli_run`
2. **编排**：`chat_job_queue`、`agent/`（`agent_turn`、消息管道、`per_coord`、workflow）
3. **模型**：`llm`（`complete_chat_retrying` → `OpenAiCompatBackend` → `api::stream_chat`）、vendor
4. **工具**：tools 表驱动、`tool_registry`、可选沙盒、`tool_result`
5. **契约**：`cm_types` / `cm_config` / `cm_llm` / `cm_agent`、`cm_api_contract`（HTTP JSON DTO + OpenAPI schemars）、`cm_sse_protocol`、`cm_web_host`（handler 壳再导出契约）

```mermaid

```

### 配置

`AgentConfig`：多段 TOML + `CM_*` → `finalize`。**`POST /config/reload`** 热更新多数字段（会话库路径等例外见 `config/hot_reload`）。键说明见 **配置说明**。

### Agent 主循环（心智模型）

- 业务侧只经 **`llm::complete_chat_retrying`**（勿在 `agent` 直连 `api::stream_chat`）。
- **P / R / E**：P = 一轮模型；R = 反思 / 终答门控（`per_coord`）；E = `execute_tools` → `ToolExecutionHost`。
- 出站消息变换：`message_pipeline` / `context_window`。
- 运行时主路径：**session_mode →（Act 句关键词启发式）→ `assess_turn_routing` → ReAct 外循环**；相位词汇见 **`phase_vocabulary`**；设计见 **`docs/design/per_state_machine_consolidation.md`**。

### Web 流式（概要）

`POST /chat/stream` → `ChatJobQueue` → `TurnRunner`（默认 `run_agent_turn`）→ LLM SSE → 工具（串行或只读并行批）→ SSE 控制面。事件与错误码以 **SSE协议** 为准；布局见 **Turn布局设计**（含 §15 过渡债、§16 Phase E）。

### 可观测性（概要）

`observability`：tracing（本地时区 RFC3339）；Web 可选 `TracingChatTurn`；JSON 日志 `CM_LOG_JSON`。管道命中计数等见 **`GET /status`**（字段以 OpenAPI / handler 为准，本文不枚举）。

## 主要模块（按职责）

增删顶层职责或 crate 边界时更新本表；**细分路径请检索源码**，不在此维护逐文件表。工具清单与参数见 **工具说明**；HTTP 面见 **命令行与路由**。

| 区域 | 职责 |
|------|------|
| **`agent/`** | 回合编排 composition：`agent_turn`、管道、`per_coord`、workflow 接合（领域核在 **`cm_agent/`**） |
| **`llm/`** | 重试完成、vendor、`api` 流式；领域实现多在 **`cm_llm/`** |
| **`tools/`** / **`tool_registry/`** | 工具实现与分发、审批、超时（经 **`cm_internal`** 再导出为 `crate::tools`）；`run_command` / `terminal_session` 在配置开启时可对 argv 级区外路径做 **`WorkspaceExternalPath`** 三态预检（`skip_arg_safety`）；需 glob/`$VAR`/`~` 且白名单含 **`bash`/`sh`** 时经 **`bash -c`** 跑整行脚本；Web 上独立 argv 的 `&&`/`|` 即使 bash 已在白名单也会再审 |
| **`sse/`** | 控制面载荷 / 编码 / hub（**`cm_sse_protocol`**，`protocol` feature 无 tokio） |
| **`web/`** | Axum、`AppState`、域路由；JSON DTO 在 **`cm_api_contract`**（WASM 与 OpenAPI 同源），handler 经 **`cm_web_host`** 再导出 |
| **`chat_job_queue/`** | `/chat*` 排队与 worker |
| **`config/`** | 加载、`finalize`、热重载（**`cm_config`**，根包 `pub use` 为 `crate::config`） |
| **`workspace/`** | 路径策略与安全打开 |
| **`memory/`** | 长期记忆 / 可选语义索引（**`cm_memory`**） |
| **`runtime/`** | 运维 CLI 退出码、导出、bench 接合（**`cm_runtime`**） |
| **`tool_result/`** | 工具输出信封 |
| **`cm_types`** | `Message` / `Tool` / 网关预设等（`protocol`） |
| **`cm_api_contract`** | `POST /chat*`、`ApiError`、`GET /status?view=shell` 等 HTTP JSON；`schemars` 生成 OpenAPI `components`（`protocol`） |
| **`cm_agent`** | 意图、外循环 FSM、完成判定等**领域核**；根包 `agent/` 承载执行面 IO |
| **`cm_turn_layout`** | canonical Turn → Web/TUI 投影（`protocol`；见 [`crates_io_single_package.md`](./design/crates_io_single_package.md)；W3 缓做） |
| **`cm_approval`** | Web 工具审批类型与 SSE 往返 |
| **`cm_chat_export`** | 会话导出信封（raw / display，`protocol`） |
| **`cm_display_rules`** | 聊天区隐藏/匹配规则（`protocol`） |
| **`crabmate-connect`** | 桌面/移动 Tauri 共用连接页：`/health` 探测、Bearer hash 交接、钥匙串 Bearer（**仅** Client 仓 [`crates/crabmate-connect`](https://github.com/noisystreet/crabmate-client/tree/main/crates/crabmate-connect)；本仓已移除） |
| **`observability`** | tracing 初始化 |

单包：crates.io **稳定版**仍为 **`crabmate` `0.4.0`**（`server` 默认 / Client 钉 `protocol`）。本树 Cargo 为 **`0.5.0-alpha.0`**（git **`v0.5.0-alpha.0`**，未上 crates.io）。原 workspace 成员为顶层 **`src/cm_*`**；根包 `src/{agent,llm,runtime,web,…}` 仍为 composition。**对外可见**：`protocol` 仅六个 `cm_*` 契约模块（无 `types`/`sse` 别名）；`server` 组合面走 `agent` / `config` / `llm`；无整模块再导出的实现为 `pub(crate)`，其余 `#[doc(hidden)]`（**不承诺 semver**，见 [`crates_io_single_package.md`](./design/crates_io_single_package.md) §2.4）。禁边见 **`scripts/check-crate-deps.sh`**、**`docs/design/crate_dep_policy.md`**、**`docs/design/web_host_extract.md`**。

## 前端（摘要）

业务 UI **源码不在本仓**（路径 A）。Leptos CSR：Client [`frontend/src/api/`](https://github.com/noisystreet/crabmate-client/tree/main/frontend/src/api) + [`sse_dispatch`](https://github.com/noisystreet/crabmate-client/tree/main/frontend/src/sse_dispatch) 消费 SSE；`app/` 聊天与工作区。设计笔记见 **`docs/frontend/ARCHITECTURE.md`**。构建：先将 [crabmate-client](https://github.com/noisystreet/crabmate-client) 克隆为同级后 `cd ../crabmate-client && make frontend`。

状态权威（避免第三真源）：壳层偏好 → `/user-data/prefs`；会话列表 → 内存 + 工作区分桶 `web_sessions.json`；流式尾段 → `stream_text_overlay`（收尾合并回 sessions）。展示全文须含 overlay 时走 `message_text_for_display_including_stream_overlay`。

## 数据与持久化（摘要）

- **会话**：默认工作区 SQLite（`conversation_store_sqlite_path`）；可关。
- **工作区**：工具与 `POST /workspace` 共用当前根；`.crabmate/` 提醒/导出等。助手 Markdown 中的相对图片路径由 Client 改写为 **`GET /workspace/file/raw`**（扩展名白名单、鉴权后 `blob:`），见 **`docs/命令行与路由.md`**。
- **用户数据**：`/user-data/*` → `$XDG_DATA_HOME/crabmate`（见 **`docs/design/user_data_dir.md`**）；**不**用浏览器 `localStorage` 存会话/偏好/LLM 覆盖。
- **桌面**：业务数据走本机或远程 `serve` 的 `/user-data`；壳**不** spawn 后端，启动后走共用**连接页**（默认预填 `http://127.0.0.1:8080/`；Bearer 首次写入钥匙串 `tauri_connect_web_api_bearer`），与 Client 仓 **[`mobile-tauri`](https://github.com/noisystreet/crabmate-client/tree/main/mobile-tauri)** 对齐（[**`crabmate-connect`**](https://github.com/noisystreet/crabmate-client/tree/main/crates/crabmate-connect)）。
