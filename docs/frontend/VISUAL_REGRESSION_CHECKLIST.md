# Leptos Web UI 视觉回归检查清单

在改动 `frontend/styles/**` 或 `frontend/src/lib.rs` 中影响布局/主题的视图后，发版或合并前建议逐项手测（无需自动化截图）。

## 主题

- [ ] **深色**：顶栏、对话区、侧栏、状态栏层次清晰；`muted` 文案可读。
- [ ] **浅色**：同上；`border-subtle` 与背景仍可分辨。

## 视口

- [ ] **宽屏（>768px）**：右侧工具栏「工作区 / 任务 / 状态 / 主题」全部可见；无多余换行。
- [ ] **窄屏（≤768px，与 `app_prefs::MOBILE_LAYOUT_BREAKPOINT_PX` / `mobile.css` 一致）**：左缘右划打开会话抽屉；右缘左划 / 视图菜单打开工作区半屏抽屉（顶部工具栏含状态/设置），点遮罩关闭；会话抽屉品牌行「筛选」按钮可开闭搜索面板；composer 附件在输入框左侧、发送/停止同槽互斥且触控 ≥44px；审批居中 modal；工作区树/任务行 ≥44px，点目录名可展开，长按出菜单，窄屏单击文件可插入 `@`。
- [ ] **浏览器选工作区（无项目池）**：「项目 → 选择工作区」打开 `workspace-browser-pick-modal`（最近列表 + 路径输入），勿依赖 `window.prompt`。

## 聊天与侧栏

- [ ] **消息元信息**：TUI 回合带角色样式（`--user` / `--assistant` / `--tool`）；右键 / 长按打开消息操作菜单。
- [ ] **长消息 / 流式**：终端流宽度与跟底正常；活跃块流式更新可见。
- [ ] **历史分页**：有更早消息时顶部「加载更早」可用（`chat-load-older`）。
- [ ] **工作区卡片头**：显示「N 项」或「加载中…」/「错误」。
- [ ] **任务卡片头**：显示「完成数/总数」或加载/错误态。
- [ ] **侧栏显隐**：宽度过渡平滑；折叠后主区无双边框。

## 审批条

- [ ] **宽屏**：居中 modal；完整 `pre` 与三个按钮可用。
- [ ] **窄屏**：居中 modal（勿贴底，以免被系统手势条遮挡）；操作钮纵向全宽 ≥44px。

## 会话弹窗

- [ ] **键盘焦点**：`Tab` 到会话行时可见 `focus-visible` 环。
- [ ] **当前会话**：左侧色条与背景区分明显。

## 骨架与状态栏

- [ ] **骨架屏 → 内容**：工作区/任务/状态加载完成后无布局跳动。
- [ ] **角色下拉**：外观与状态 chip 协调；`focus-visible` 有环。
- [ ] **`prefers-reduced-motion: reduce`**：列表渐入、状态点脉冲、侧栏过渡、审批条展开动画关闭或等价静态呈现。

## 构建

- [ ] `cd ../crabmate-client && make frontend` 成功（确认 `@import` 子样式被打包）。
